Introduction

JavaScript is a versatile scripting language used on the web.

It allows developers to make interactive web applications.

JavaScript can be run in the browser or on the server using Node.js.

console.log("Hello, world!");

You can write JavaScript directly in an HTML file.

It is one of the core technologies of the web.

  • Client-side scripting
  • Lightweight
  • Dynamic
  • Interpreted
  • First-class functions
Variables

Variables store data values in JavaScript.

You can use `var`, `let`, or `const` to declare them.

let name = "Alice";

`let` and `const` were introduced in ES6.

`const` is used for values that don’t change.

Functions

Functions are blocks of reusable code.

function greet(name) { return "Hello " + name; }

Functions can take parameters and return values.

They help reduce repetition in code.

const add = (a, b) => a + b;
Loops

Loops are used to repeat code a number of times.

for(let i = 0; i < 5; i++) { console.log(i); }

Common loops include `for`, `while`, and `do...while`.

Use loops to iterate over arrays and objects.

let i = 0; while(i < 3) { i++; }
Objects

Objects are collections of key-value pairs.

const person = { name: "Alice", age: 25 };

They are used to model real-world entities.

Access values using dot or bracket notation.

console.log(person.name);
